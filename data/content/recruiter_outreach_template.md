# data/content/recruiter_outreach_template.md — Recruiter Outreach Template
# ════════════════════════════════════════════════════════════════
# Template for recruiter and hiring manager outreach messages.
# The draft_application_response and draft_referral_message skills read this.
# Replace all [YOUR_...] placeholders with your actual content.
#
# RULES:
#   - Salutation for recruiters and DMs: "Hi [Name]," — NEVER "Dear"
#   - "Dear" is for cover letters only
#   - Never exceed 120 words for a DM
#   - Never fabricate metrics or experience
#   - Use [YOUR_CREDENTIAL_HOOK] from experience_bank.md (do not invent)
# ════════════════════════════════════════════════════════════════


# ── RECRUITER EMAIL STRUCTURE ─────────────────────────────────
# Subject: "[YOUR_ROLE_TARGET] application — [YOUR_NAME]"
#
# Hi [Recruiter Name],
#
# [PARA 1 — 2-3 sentences]
# Brief intro + specific interest in the company/role. Name the role explicitly.
# Reference something specific from the JD or company (not generic).
# [YOUR_CREDENTIAL_HOOK — build from candidate_profile.json experience[]]
#
# [PARA 2 — 2-3 sentences]
# Most relevant experience mapped to the role. One metric from experience_bank.md.
# Honest about domain differences if present.
#
# [PARA 3 — 1-2 sentences]
# Relocating sentence (market-appropriate):
#   UK:   "I am based in [YOUR_CITY] and am actively seeking roles in the UK under
#          Skilled Worker Visa sponsorship. [City] is a preferred destination and I
#          am fully prepared to relocate upon receiving an offer."
#   NL:   "... kennismigrant permit ..."
#   DE:   "... EU Blue Card ..."
#   DK:   "... Pay Limit Scheme ..."
#   IE:   "... Critical Skills Employment Permit ..."
#   AE:   "... UAE Employment Visa ..."
#
# [CLOSING]
# Kind regards,
# [YOUR_NAME]
# [YOUR_PHONE] | [YOUR_EMAIL]


# ── LINKEDIN DM STRUCTURE (80–120 words) ─────────────────────
# Hi [Name],
#
# [Company hook — 1 sentence: what caught your attention about this company/role]
# [Credential hook — 1 sentence: YOUR_CREDENTIAL_HOOK]
# [Relocating sentence — 1 sentence, market-appropriate]
# [CTA — 1 sentence: happy to share CV / jump on a call]
#
# Best,
# [YOUR_NAME]


# ── HIRING MANAGER COLD DM (120–160 words) ───────────────────
# For Directors / VPs / Heads of [YOUR_DOMAIN] — internal hiring managers.
# NOT for: HR/P&C, external recruiters, peer contacts.
#
# Hi [Name],
#
# [Company hook — 1 sentence: what they are building or their known challenge]
#
# [3 impact bullets in action-noun format:]
# • [Scaled capability]: [verb + what + commercial growth metric]
# • [Delivered value]: [verb + what + financial/efficiency outcome]
# • [Future-proofed]: [verb + capability-building + outcome]
#
# [Closing — 2 sentences]
# Express interest in connecting briefly. Soft CTA — not a CV push.
#
# Best,
# [YOUR_NAME]


# ── HR / P&C COLD DM (under 70 words) ────────────────────────
# For HR Business Partners or People & Culture contacts.
# Question-first, one credential hook, soft CV offer.
#
# Hi [Name],
#
# [Question: "Are you the right person to speak with regarding the [Role] role at [Company]?"]
# [1 sentence credential hook]
# ["Happy to share my CV if it would be useful."]
#
# Best,
# [YOUR_NAME]


# ── [YOUR_CREDENTIAL_HOOK] — Build Your Own ───────────────────
# This is the key differentiating line that appears in most outreach.
# Build it from candidate_profile.json:
#
#   "[years_of_experience]+ years in [domains.primary.label] —
#    [experience[0].role] at [experience[0].company]
#    ([experience[0].focus_areas])
#    and [experience[1].role] at [experience[1].company]."
#
# EXAMPLE (analytics domain):
#   "8+ years in product and growth analytics — Lead Analytics Manager
#    at a major ecommerce platform (CRM, experimentation, pricing) and
#    Analytics Manager at a marketplace (dynamic pricing, supply chain)."
#
# RULE: Only use experience and companies from experience_bank.md.
#       Never inflate tenure or seniority.
